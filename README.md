# Aerial-distant


In this extention It will measure the linear displacement of a web page or app.

### It usually cannot run on restricted pages such as:

*  chrome:// pages
*  Chrome Web Store pages
*  New Tab page
*  Other extension pages
*  Some browser PDF or protected pages
